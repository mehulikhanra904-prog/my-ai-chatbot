
# 🤖 My AI Chatbot

A full-stack AI chatbot built using the MERN stack, Google Gemini API, and MongoDB Atlas.

The application allows users to chat with an AI assistant, save conversations to MongoDB, and load previous chat history.

## 🚀 Features

- 🤖 AI-powered conversations using Google Gemini
- 💬 Real-time chat interface
- 🗄️ Chat history stored in MongoDB Atlas
- 🔄 Previous conversations can be loaded
- 🌙 Dark mode
- ⌨️ Send messages using Enter
- ⏳ AI typing/loading animation
- 📱 Responsive frontend
- 🔐 Environment variables for API keys and database credentials
- ⚡ React + Vite frontend
- 🟢 Node.js + Express backend
